# Stanford Assignment Solutions · Stanford 作业教学解答

## Source | 题面

Use the assigned edition, starter code and submission instructions. Map each written or programming deliverable to its question, including nested parts. Carry forward the assumptions, data split, interfaces and filenames on which the answer depends. When available, read the course template and a rendered exemplar to identify the role of each color, typeface and heading.

以本期原题、起始代码和提交说明为准。逐问对应书面与编程交付项，核实嵌套题号。保留解题所依赖的假设、数据划分、接口与文件名。有 LaTeX 模板和成品样页时，对照两者辨明颜色、字体与标题各自标示什么。

## Solutions | 解答

Give each independently numbered part one page. Keep official numbering. Use bold roman-numbered headings for the quantities, claims or comparisons the question asks for. Where a proof needs several steps, name the intermediate result that the next step uses. Write the body for a reader returning to the subject. Explain what is given, carry one calculation through the difficult step, and show why it answers the question. Follow a worked example with the general argument when proof is required.

每个独立小问占一页，保留原题号。用粗体罗马序号小标题标明题目所求的量、待证命题或比较对象。证明需要分步时，写明下一步要用到的中间结果。正文讲给重新学这门课的人听。先说明已知条件，带读者算过最容易卡住的一步，再说明这一步为什么能回答原题。证明题用例子建立直觉，再交代一般情形成立的理由。

Run the required code on the specified inputs and check any supplied tests. Record the split, seed and stopping rule when they affect the result. Link reported numbers and curves to that run. Label a hand-sized teaching example separately from the experiment.

按题目指定的输入运行代码，有配套测试时核对测试结果。数据划分、随机种子或停止条件影响结果时，写明取值。正文数字和曲线取自同一次运行。另举的小算例写清条件，与实验结果区分。

## Figures | 图示

Start with the step a reader needs to see. Draw a calculation or a change of state as an editable vector diagram with fine dark arrows, black serif labels and pale fills for distinct roles. Label each arrow with its operation. For measured results, plot the actual data, label the axes and units, and mark the point or interval to read. Align scales and match the objects across panels. Pair color with a line style or marker that also works in grayscale.

先找出读者需要亲眼看见的那一步。运算和状态变化用可编辑矢量图呈现，深色细箭头标明操作，黑色衬线字标注对象，浅色填充区分角色。实验图用实际数据绘制，标明坐标和单位，点出要读的位置或区间。并排比较时对齐刻度，核对各图标记的是同一对象。用线型或点形配合颜色，使灰度打印也能辨认。

Place the caption directly below the figure. Tell the reader where to start, read one value or relationship, and explain what it establishes for this question. Cover the caption and check that the drawing itself shows the change.

图注紧跟图形。指出先看哪里，读出一个数值或关系，再说明它怎样回答本题。遮住图注，检查能否从画面本身看出变化。

## Delivery | 交付

Follow the requested layout. For the black-text edition, use a serif question number at about 17 pt, sans serif answers at 10 pt and serif captions. Use ForestGreen for answers and captions when reproducing a template that specifies it. Begin the first page with the first question. Set the supplied footer on one line in its approved wording. Match headings, equations, figures, example values and conclusions across language editions.

版式按本次任务约定。黑字版用约 17 磅衬线题号、10 磅无衬线正文和衬线图注。复刻明确指定 ForestGreen 的模板时，解答与图注沿用该色。首页从第一小题起排。指定页脚按确认原文单行排印。各语言版本的标题、公式、图表、例值与结论逐一对应。

Keep the PDF, editable LaTeX, figures and required code in the requested edition directories. Put build files in the workspace. Rebuild and render each edition. Compare the page sequence with the source, check a figure value against its calculation, and inspect the densest pages at reading size. Resolve overflow by removing repetition or rearranging the figure while keeping its labels legible.

PDF、可编辑 LaTeX、配图与应交代码归入指定语言目录，构建文件放工作区。重新编译并渲染各版，对照原题逐页核对编号，回算图中的数值，按实际阅读大小检查密排页。遇到溢页，先删重复解释或重排图形，保留图内标注的可读字号。
